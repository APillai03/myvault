# MyVault (Next.js, JavaScript, CSS Modules)

Routes:
  /                -> Google sign-in
  /dashboard       -> Dashboard
  /my-inventory    -> My Inventory
  /my-documents    -> My Documents
  /add-item        -> Add a New Item
  /add-document    -> Add a Document

Run (from the folder that contains package.json):
  npm install
  npm run dev
Then open http://localhost:3000
